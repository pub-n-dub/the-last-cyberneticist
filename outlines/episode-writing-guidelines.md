# Episode Writing Guidelines

House rules for drafting future episodes of `The Last Cyberneticist` so runtime, structure, and prose style stay consistent.

Current writing date: Wednesday, August 12, 2026.

## Fixed runtime rule

All mainline episodes should land at:

- `24-26 minutes` finished spoken length

Practical target:

- aim for `about 25 minutes`

Revision rule:

- if a draft is likely under `23 minutes`, it is too short and needs expansion
- if a draft is likely over `27 minutes`, it is too long and needs tightening

This rule exists because the first published episodes already established the real shape of the show:

- Episode 1: about `25m 34s`
- Episode 2: about `23m 49s`
- Episode 3: about `25m 55s`

The series should now standardize around that actual range rather than the earlier planning estimate.

## Draft-length rule

When writing from scratch, draft for:

- `2,700-3,200 spoken words`

This is not a mechanical law, because delivery pace changes with emphasis, pauses, and density of thought. It is a drafting range that usually keeps the script near the series runtime when read in a reflective speaking voice.

If a script falls well below `2,500` words, assume it is probably too thin unless the prose is unusually slow and meditative.

## Script form rule

Scripts should be written as readable spoken prose, not as stacked note lines.

Use:

- full paragraphs
- complete sentences
- short quoted lines only for titles, closing moves, or occasional emphasis
- section headings only when useful during drafting

Avoid:

- one-sentence paragraphs repeated for pages at a time
- bullet-like script blocks unless they will be rewritten into prose
- compressed seminar prose that sounds written rather than spoken

The page should be easy to read aloud without constant scrolling through broken fragments.

## Structural rule

Every episode should contain these five moves in some form:

1. A clear opening problem or question
2. A development section that explains what changed or what we are really looking at
3. A central claim stated plainly
4. A return from abstract ideas to a concrete machine, case, or consequence
5. A closing step that points to the next episode or next experiment

This does not mean every episode needs rigid segment labels. It means the argument should progress clearly enough that a listener can retell it afterward.

## Voice rule

The house voice of the show should remain:

- reflective
- serious
- historically aware
- technically grounded
- skeptical of spectacle
- interested in architecture, repair, control, and embodiment

The scripts should sound like one person thinking carefully in public, not like marketing copy and not like an academic paper read aloud.

## Content-balance rule

Future scripts should prefer:

- one main problem per episode
- one or two supporting historical figures, texts, or machines
- repeated return to the concrete stakes of the series

Future scripts should avoid:

- cramming too many names into one episode
- biography for its own sake
- turning a paper episode into a compressed lecture
- letting present-day AI spectacle dominate the framing

## Bench-series rule

For the `Hero-1` run in particular:

- each episode should center one real blocker, repair step, architectural question, or experimental milestone
- theory should clarify the machine, not replace it
- every episode should end with one concrete next action

## Delivery checklist

Before treating a draft as finished, check:

- Is it likely to read at `24-26 minutes`?
- Does it have one central claim?
- Does it read as prose rather than notes?
- Is the listener told why this episode matters now?
- Does it return to the machine, the bench, or the practical consequence?
- Does the ending create momentum into the next episode?

## Default instruction for future drafting

Unless explicitly told otherwise, every new episode draft should be written to these defaults:

- target `25 minutes`
- draft in prose paragraphs
- keep one central claim
- end with one concrete next step
- revise for spoken readability, not just conceptual completeness
